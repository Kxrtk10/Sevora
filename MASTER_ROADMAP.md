# Master Roadmap

This is Sevora's execution roadmap. It contains only work that directly helps build the company, prove capability, acquire clients, or scale delivery.

## Phase 1: Company Foundation

- Complete SevoraOS structural refactor.
- Finalize engineering, design, architecture, quality, deployment, and documentation standards.
- Establish reusable templates for product, research, architecture, API, database, meetings, proposals, and case studies.
- Define the operating cadence for decisions, roadmap updates, and delivery reviews.

## Phase 2: Reference Solutions

- Build ClinicFlow as the first polished reference solution.
- Define ClinicFlow PRD, architecture, data model, and API contracts.
- Create demo workflows for patient intake, appointment management, staff tasks, and follow-up.
- Scaffold RestaurantOS and TeamMind after ClinicFlow has a working demo standard.

## Phase 3: Website

- Build the public Sevora website around products, solutions, proof, company, and contact.
- Publish ClinicFlow as the first concrete proof asset.
- Add solution pages for Healthcare, Restaurants, and Enterprise.
- Add case studies only when real product or client proof exists.

## Phase 4: Client Acquisition

- Convert ICP, discovery, pricing, and proposal docs into a repeatable business development motion.
- Use ClinicFlow to support healthcare discovery conversations.
- Build a focused outbound list for healthcare operators.
- Create proposal packages from real discovery calls.

## Phase 5: Own Products

- Review existing owned product concepts under `products/own`.
- Select one owned product to validate after ClinicFlow proves the delivery standard.
- Convert the selected product into a PRD, architecture plan, and build roadmap.
- Retire or park product ideas that do not match Sevora's execution focus.

## Phase 6: Scaling

- Standardize delivery from reference solution to client implementation.
- Build reusable product modules only after repeated use across real projects.
- Hire for engineering, design, and business development when workload justifies it.
- Turn SevoraOS into a lightweight company intelligence layer with searchable decisions, products, research, and delivery records.
