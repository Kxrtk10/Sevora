# Site Architecture

The Sevora website should explain what Sevora builds, prove capability, and create clear paths to business conversations.

## Primary Navigation

- Home
- Products
- Solutions
- Work
- Company
- Contact

## Core Routes

- `/` - positioning, proof, priority solutions, and contact path.
- `/products` - owned products and reference solutions.
- `/solutions` - healthcare, restaurants, enterprise, and education.
- `/work` - case studies, demos, and proof assets.
- `/company` - mission, principles, and operating standard.
- `/contact` - focused inquiry flow.

## Architecture Standard

The site should reference SevoraOS content as source material, but public pages should be written for buyers, not internal operators.
