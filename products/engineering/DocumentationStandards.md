# Documentation Standards

Documentation should help future employees act faster.

## Standards

- Start with purpose, status, owner, and related links.
- Keep product docs close to the product.
- Link to source documents instead of copying them.
- Archive or rename outdated docs when they still have historical value.
- Use templates for PRDs, architecture notes, APIs, databases, research, and meetings.
- Update documentation as part of the work, not after memory fades.
