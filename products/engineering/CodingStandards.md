# Coding Standards

Code should be readable, testable, and consistent with the local project.

## Standards

- Follow the framework and style already present in the codebase.
- Use clear names that express domain meaning.
- Keep functions small enough to reason about without hiding essential flow.
- Prefer structured parsing and validation over ad hoc string handling.
- Add comments only where they clarify non-obvious decisions.
- Remove dead code before shipping.
